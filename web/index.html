Fleet server config helper

Answer a few questions and get a ready-to-use Fleet server config as a fleet.yml file, environment variables or command-line flags.

Nothing you type leaves this page. There is no server behind it, and your browser is told to block every outgoing request. 


  










  
Field names follow Fleet's config.go. This is a personal project, not an officially supported Fleet tool. Deploying on Hetzner Cloud? Try the Hetzner config helper.
